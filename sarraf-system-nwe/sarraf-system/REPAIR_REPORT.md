## ٢. ئەو نۆ کێشەیەی خۆت دۆزیتەوە

هەموویان لە پێنج ڕەگەوە دەهاتن، نەک نۆ کێشەی جیاواز. ئەمە هۆکاری ئەوەیە کە «شتێک چاک دەکەین و شتێکی تر تێک دەچێت» کۆتایی هات.

| ڕەگ | ئەوەی تۆ دیتت | چاککرا لە |
|---|---|---|
| فیش پێش دڵنیابوون لە ناردن دەنووسرا | «ناردن سەرکەوتوو نەبوو» · دووبارەبوونەوە لە هەوڵی دووەم | فەیسی ١ |
| نرخ حساب دەکرا نەک دابنرا | نرخەکان زۆر هەڵە بوون | فەیسی ٢ |
| فیش → مامەڵە مامەڵەیەکی ڕاستەقینە نەبوو | یەن زیاد نەدەبوو · قوفڵ نەبوو | فەیسی ٣ |
| نێرەر شاشەی ئۆپەرەیتەری دەبینی | دۆلار پیشان دەدرا · دوگمەی ئیدیت · دراوی هەڵە | فەیسی ٤ |
| کۆکردنەوە لای وێبگەڕ دەکرا | (دۆزینەوەی پشکنینەکەم) | فەیسی ٥ |

## ٣. هەشت فەیسەکە

### فەیسی ١ — ناردنی فیش دەبێت کاربکات
ناردنێک کە وەڵامەکەی ون بووە، تۆمارێک بەجێدەهێڵێت. لە بارکردنی دواتردا ئەو تۆمارە دەخوێندرێتەوە: نێرەر پێی دەوترێت فیشەکانی گەیشتوون، لە جیاتی ئەوەی دووبارە بینێرێت و وەک دووبارە ڕەت بکرێتەوە.

### فەیسی ٢ — یەک ڕەیتیۆ بۆ هەر دراوێک
`1 USD = X`. هیچ سپرێدێک لە کاتی نرخاندندا دروست ناکرێت. قازانج لەوەوە دێت کە ڕەیتیۆکە لەنێوان ڕۆژی کڕین و ڕۆژی فرۆشتندا جوڵابێت — کە ئەوە پێشتر لە کۆست-بەیسی مەخزەندا دەپێوردرا.

### فەیسی ٣ — فیش دەبێتە مامەڵەیەکی ڕاستەقینە، یەکجار
یەن زیاد دەبێت و دۆلار کەم دەبێتەوە، وەک مامەڵەی ڕاستی. کۆمەڵە فیشێک تەنها **یەکجار** دەتوانرێت ببەسترێتەوە بە مامەڵەیەکەوە؛ هەڵوەشاندنەوەی مامەڵەکە فیشەکان ئازاد دەکاتەوە. `total = amount × rate` لە داتابەیسدا پشکنین دەکرێت.

### فەیسی ٤ — نێرەر تەنها ئەوە دەبینێت کە خۆی ناردوویەتی
ناوی وەرگر لە هەر شوێنێک دەخوێندرێتەوە کە خزمەتگوزاری پارەدان داینابێت. هیچ دراوێکی بنەڕەتی نییە کە بکەوێتە جێی دراوی نەخوێندراوە. دوگمەی ئیدیت تەنها بۆ ستافە.

### فەیسی ٥ — یەک کۆکانەی canonical، لە سێرڤەرەوە
`sarraf_batch_summary`: ئەدمین و نێرەر هەمان بایت دەخوێننەوە. کۆی ڕەسەن بە دراوی خۆی، بەرامبەری دۆلاری لە تەنیشتی، هەریەکەیان لەگەڵ ئەو ڕەیتیۆیەی دروستی کردووە. سەرەتا کۆ، پاشان یەکجار دابەش، پاشان round — نەک کۆکردنەوەی ژمارە round کراوەکان.

`summary_version` کاتێک دەجوڵێت کە شتێک بجوڵێت کە کۆکانەکە بگۆڕێت. پشکنینی کۆتایی ئەو وەشانە دەڵێت کە لەسەری بڕیاری داوە؛ ئەگەر جوڵابێت، `409 stale_summary`.

### فەیسی ٦ — بەشی قەرز
- **پسووڵەی ژمارەدار** (`V-2026-000001`) — بەبێ بۆشایی، چوونکە پسووڵەیەکی سڕاو لە ژمارەیەکی گەڕاوە جیا ناکرێتەوە
- **دانانەوەی دوولایەنە** — یەک تۆمار هەردوو قەرزەکە کەم دەکاتەوە
- **بەخشینی قەرز** — دەچێتە خەرجی، نە دەسڕدرێتەوە نە وەک «دراوە» تۆمار دەکرێت؛ بڕیاری خاوەنی سیستەمە
- **`debt_events`** — هەر گۆڕانێکی قەرز خۆی تۆمار دەکات، لە داتابەیسەوە

### فەیسی ٧ — پاراستن
- **چوار کلیلی دووبارەبوونەوە**: وێنە، ژمارەی مامەڵە، ژمارەی فرۆشیار، و کلیلی هاوبەش (هەمان دراو + بڕ + ڕۆژ + وەرگر). سێی یەکەم ڕەتکردنەوەن؛ چوارەم **گومانە** بۆ مرۆڤ، چوونکە شێوەی پارەدانێکی دووەمی ڕاستەقینەشە
- **واژۆی خوێندنەوە**: خوێنەرەکە هاشی وێنەکە و دایجێستی ژمارەکان تۆمار دەکات؛ ئەگەر ژمارەیەک لە ڕێگادا بگۆڕدرێت، لە دەرگاوە ڕەت دەکرێتەوە. `1200` ناتوانرێت ببێتە `12000`
- **سنووری داواکاری** لەسەر ڕێگاکانی خۆمان، لە داتابەیسدا نەک لە پرۆسێسدا
- **`pending` ی قاسە**: پارەی دراو ≠ پارەی پشتڕاستکراو

### فەیسی ٨ — ١٣ ڕەوتی کاری §14
هەموو ١٣ ڕەوتەکە بە تەواوی دەڕۆن بەسەر داتابەیسێکی ڕاستەقینەدا، ٦١ هەنگاو. ئەم پشکنینە **کێشەیەکی ڕاستەقینەی دۆزییەوە**: هیچ فەرمانێک نەبوو کە پارەدانی نووسینگە پشتڕاست بکات. `office_assignment_status` بەهای `confirmed` ـی هەبوو و هیچ شتێک دایناندەنا — نووسینگە پارەی دەدا و هەرگیز دان بەوەدا نەدەندرا کە زیمان قەرزاری ئەوە. `sarraf_office_payment_confirm` ئێستا هەیە.

## ٤. یاساکانی بنەڕەتی کە ئێستا داتابەیس جێبەجێیان دەکات

نەک ڕووکار — داتابەیس. ڕووکارێک دەتوانرێت پێچ بدرێت؛ یاسایەک لە داتابەیسدا نا.

| یاسا | چۆن |
|---|---|
| کڕیار تەنها فیشی فرۆشتنی خۆی دەنێرێت | تریگەر لەسەر `receipt_batches` و `receipts` |
| ژمارەکانی وێنەکە ناگۆڕدرێن | دایجێستی واژۆکراوی خوێندنەوە |
| کۆمەڵە فیشێک یەکجار دەبەسترێتەوە | `sarraf_receipt_already_converted` |
| `total = amount × rate` | `sarraf_assert_total_matches_rate` |
| دەفتەر هەمیشە هاوسەنگە | `sarraf_trial_balance_check` |
| مێژووی دارایی ناسڕدرێتەوە | تریگەری append-only لەسەر ٦ خشتە |
| هیچ کەس داتای کەسێکی تر نابینێت | RLS + مەرجی خاوەندارێتی لە هەموو فەنکشنێکدا |
| فەرمانێک دووجار ڕوونادات | `command_key` + `accounting_commands` |

## ٥. ئەوەی نەکراوە

بە ڕاستگۆیی:

- **مۆری ژمێریارێکی پسپۆڕ لەسەر پلانی هەژمارەکان** — ئەمە بڕیاری تۆیە، نەک بڕیاری من. ٢٠ هەژمار هەیە و لۆژیکەکەی دروستە، بەڵام ژمێریارێک دەبێت پێداچوونەوەی بکات.
- **تاقیکردنەوە لەسەر staging پێش بەرهەمهێنان** — هیچ ژینگەیەکی staging نییە.
- **پلانی گەڕانەوە (rollback)** بۆ هەر مایگرەیشنێک نەنووسراوە. هیچ مایگرەیشنێک داتا ناسڕێتەوە، بۆیە گەڕانەوە شیاوە، بەڵام نەنووسراوە.
- **دەستڕاگەیشتن (accessibility)** — `ReceiptForwardingCenter` هێشتا `aria` ی تەواوی نییە.
- **دوو وێنەکەی fixture ی §12** — وێنەکانم نییە؛ ئەوەی دەتوانرا لە ڕووی داتاوە بپشکندرێت (هیچ IQD، دراوی ڕاست، فی جیا، دۆلار بە ڕەیتیۆی دەستی) پشکنراوە.
- **`require_attestation` کوژاوەیە** بە ئەنقەست. کردنەوەی پێش ئەوەی هەموو کلاینتەکان واژۆ بنێرن، وەرگرتنی فیش ڕادەگرێت. کاتێک دڵنیا بوویت هەموو بەکارهێنەران وەشانی نوێیان هەیە، بیکەرەوە:
  ```sql
  update public.receipt_control_policy set require_attestation = true;
  ```

## ٦. ئەوەی پێویستە تۆ بیکەیت

1. **مایگرەیشنەکان ڕەن بکە** بە ڕیزبەندی. دوایین چوارەکە:
   ```
   202608170001_debt_register.sql
   202608180001_receipt_duplicate_keys.sql
   202608180002_ocr_attestation.sql
   202608180003_rate_limit_and_pending.sql
   202608190001_office_payment_confirmation.sql
   ```
2. **`verified` بکە بە پشکنینێکی پێویست** لە ڕێککارەکانی پاراستنی لقی GitHub.
3. **ڕەیتیۆی ئەمڕۆ دابنێ** پێش هەر مامەڵەیەک — بەبێ ئەوە، فەرمانەکان بە هەڵەیەکی ڕوون ڕادەوەستن نەک بە ژمارەیەکی هەڵە.
4. **پلانی هەژمارەکان بدە بە ژمێریارێک** بۆ مۆرکردن.
